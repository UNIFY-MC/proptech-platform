# Story 019.6 — `packages/ui` v1: tokens canónicos + 10 primitives partilhados

**Story ID:** 019.6
**Epic:** epic-019-brownfield-cleanup-2026-q2
**Covers debts:** FE-001 (Critical, P1+P2), FE-010 (Medium), FE-013 (Medium), FE-016 (High), FE-017 (High)
**Effort:** XL
**Sequence:** Fase B (P1) → Fase C (P2 + P3)
**Status:** Draft

## As a

Mário (custo de mudança de marca) e vertical-builder (cada nova vertical replica problema)

## I want

`packages/ui` enriquecido com (P1) tokens canónicos partilhados e (P2) 10 primitives partilhados — para servir de fundação a todas as apps (dashboard, v2, v4, v5, futuras)

## So that

Mudanças de marca ou design tokens passem a ser one-source-of-truth; LoginScreen / Sidebar / Modal / Button deixem de ter 4 implementações independentes; novas verticais herdem fundação consistente; o sub-fase P3 (migration por app) fica viabilizado.

## Acceptance Criteria

### P1 — Tokens (Fase B)

1. **AC-1** — `packages/ui/src/tokens/colors.css` criado com light + dark conforme CLAUDE.md root (var `--bg`, `--surface`, `--blue`, `--green`, etc.).
2. **AC-2** — `packages/ui/src/tokens/typography.css` criado — Inter (300/400/500/600/700) + JetBrains Mono (400/500/600). Hierarquia documentada.
3. **AC-3** — `packages/ui/src/tokens/radius.css`, `breakpoints.css`, `motion.css` criados.
4. **AC-4** — `packages/ui` exporta `theme.css` que agrega os 5 token files.
5. **AC-5** — Chave canónica `localStorage.proptech-theme` documentada; script de migração de `v1theme` / `v2theme` / `dashboard-theme` em `packages/ui/src/theme-migration.js`.
6. **AC-6** — Documentação em `packages/ui/README.md` — como importar tokens numa app.

### P2 — Primitives (Fase C)

7. **AC-7** — 10 primitives implementados em `packages/ui/src/components/`:
   1. `<Button>` (variants: primary, outline, green, ghost)
   2. `<Input>`
   3. `<Badge>` (variants: blue, green, gold, red, purple)
   4. `<Table>` (header + cells + hover)
   5. `<KPICard>` (label + value + sub)
   6. `<Sidebar>` (190px expanded · 44px collapsed · sections uppercase)
   7. `<Modal>` (560px default · header + body)
   8. `<ErrorBoundary>` (fallback UI partilhado)
   9. `<Skeleton>` (skeleton screens)
   10. `<SkipToContent>` (a11y baseline)
8. **AC-8** — Cada primitive tem teste em RTL (depende de 019.8) — smoke + 1 variant chave.
9. **AC-9** — Storybook (ou alternativa MDX) com exemplo de uso por primitive.

## Risk & Rollback

- Tokens são additive — apps existentes continuam a funcionar com tokens locais até migrarem
- Primitives são opt-in — apps adoptam quando migrarem
- Risco: divergir token canónico de tokens reais em apps (V5 forest/emerald é exception documentada via ADR)
