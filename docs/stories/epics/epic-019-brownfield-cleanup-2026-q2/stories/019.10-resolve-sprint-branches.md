# Story 019.10 — Resolver branches sprint orfãs (merge ou descarte documentado)

**Story ID:** 019.10
**Epic:** epic-019-brownfield-cleanup-2026-q2
**Covers debts:** OPS-004 (Medium)
**Effort:** M
**Sequence:** Fase A
**Status:** Draft

## As a

Mário e qualquer agente que crie próximo sprint (conflitos de merge crescem com idade)

## I want

Resolver as 7+ branches `sprint/*` não mergeadas em `main` — cada uma com decisão explícita: merge OU descarte documentado

## So that

Próximo sprint não acumule conflitos de merge significativos; histórico de decisões fique claro; trabalho perdido em branches abandonadas seja recuperado ou explicitamente descartado.

## Acceptance Criteria

1. **AC-1** — Inventário completo das branches sprint em `docs/sprint-branches-triage-2026-05.md`:
   - `sprint/crm-attio-week1`
   - `sprint/crm-attio-week2`
   - `sprint/truth-week1`
   - `sprint/truth-week2`
   - `sprint/truth-week3`
   - `sprint/cookai3-week1`
   - `sprint/cookai3-week2`
   - + qualquer outra detectada via `git branch -r | grep sprint/`
2. **AC-2** — Por branch, decisão documentada:
   - **MERGE** — branch tem trabalho útil que deve entrar em main
   - **DROP** — trabalho substituído / abandonado; documenta-se motivo
   - **PRESERVE** — manter como referência histórica (tag em vez de branch)
3. **AC-3** — Para MERGE: Preview Vercel verde → merge sequencial em main (mais antigas primeiro) → smoke test após cada merge → branch eliminada.
4. **AC-4** — Para DROP: branch tag-ada como `archive/sprint-<name>-2026-05-dropped` antes de eliminar; ADR ou referência em commit explica racional.
5. **AC-5** — Para PRESERVE: branch convertida em tag `archive/sprint-<name>-2026-05-preserved`.
6. **AC-6** — 0 branches `sprint/*` >30 dias no remoto após esta story.
7. **AC-7** — Política de branches actualizada em CLAUDE.md ou `.claude/state/processes/branch-policy.md`:
   - Branches sprint têm TTL de 30 dias por defeito
   - Trigger automático (cron ou hook) avisa quando branch passa o threshold

## Dependencies

- **Mário tem rubrica final** em cada decisão (especialmente branches que tocam V2 produção)
- **@devops** executa pushes / merges (Regra autoridade @devops)
- Recomendado: fazer após **019.5** (Bia→Mia merged) — uma branch a menos

## Risk & Rollback

- Branches mergeadas em produção: smoke test em Preview obrigatório antes de cada merge
- Branches DROP têm tag — recuperáveis se for engano
- Rollback de merge: revert do merge commit
