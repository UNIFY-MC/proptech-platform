# Story 019.12 — Inventariar e versionar Edge Functions críticas

**Story ID:** 019.12
**Epic:** epic-019-brownfield-cleanup-2026-q2
**Covers debts:** OPS-003 (High)
**Effort:** L
**Sequence:** Fase B
**Status:** Draft

## As a

Mário (rollback / debug de Edge Functions impossível sem fonte em git) e agentes que precisem alterar Edge Function

## I want

Que pelo menos as Edge Functions críticas de V1 (~17 funções: auth, iam, mia-chat, swarm workers core, v4 contracts, v5 OCR, etc.) sejam exportadas para `supabase/functions/` no monorepo e versionadas em git

## So that

Próxima alteração de Edge Function tenha fonte rastreável; rollback seja `git revert + supabase functions deploy`; funções de teste em produção (`auth-test`, `admin-ui-test`, `agent-test`) sejam removidas.

## Acceptance Criteria

1. **AC-1** — Inventário completo de todas as 67 Edge Functions activas em V1 documentado em `docs/edge-functions/v1-inventory-2026-05.md`:
   - Nome
   - Versão actual
   - Categoria (auth / iam / mia / swarm / v4 / v5 / test / utility / one-shot)
   - Decisão: VERSIONAR / REMOVER / MANTER (sem versionar — caso justificado)
2. **AC-2** — Pelo menos 17 funções críticas exportadas para `supabase/functions/<name>/index.ts` + `deno.json` se aplicável:
   - mia-chat (v4)
   - iam-related (login, portal-token-login, has-permission, etc.)
   - swarm workers core (orchestrator, worker-haiku, etc.) — com fix de haiku_json_parse
   - v4-energia: contract simulation, change-supplier
   - v5-manutencao: OCR, magic-link, etc.
   - core: ask-property007-intent
3. **AC-3** — Funções de teste removidas via Dashboard:
   - `auth-test`
   - `admin-ui-test`
   - `agent-test`
4. **AC-4** — `supabase/functions/README.md` documenta:
   - Convenção de naming
   - Como deploy local (`supabase functions deploy <name>`)
   - Como deploy via MCP
5. **AC-5** — Para V2 produção (`eozklslwfaqujaijvdnl`) — inventário apenas (NÃO mover sem aprovação Mário). Doc em `docs/edge-functions/v2-inventory-2026-05.md`.
6. **AC-6** — Funções one-shot V2 (`migrar-faturas`, `migrar-fatura`) — desactivadas via story 019.13.
